How to Use the Metin2 Okey Helper

The app's goal is not to play the game for you, but to help you follow it more consciously.

1) Close off tiles

Close off the tiles that appear or that you use in the helper board. This clears up the remaining pool.

2) Watch the top odds

The strongest runs and triple sets that can still be formed from the remaining tiles are listed by score.

3) Choose your move accordingly

Prioritize the highest-scoring combinations to build a more stable scoring plan.

4) Practice in test mode

On the Play on Web page you can run simulations with the same scoring rules and get in some practice.

Why the Metin2 Okey Helper?

The mobile app was designed to make combination tracking easier, especially in fast-paced rounds.

Live combination coach

Keeps the most valuable moves, like a 100-point 6-7-8 same-color run, at the top based on the remaining tiles.

Matches the scoring rules

123-678 run points, mixed-run points and triple n-n-n points are all calculated with the same logic.

Fast, simple, focused

No clutter of menus; a screen built for quick decisions at a glance during the game.

Bonus content: web test mode

An educational test area, separate from the mobile experience, giving extra support to anyone who wants to learn the game.
