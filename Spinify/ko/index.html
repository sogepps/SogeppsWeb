인터페이스와 프리셋이 사용자의 언어에 맞게 표시돼요.

다크 모던 UI

SVG 휠과 부드러운 애니메이션으로 세련되게 디자인됐어요.

Spinify 작동 방식

아이디어에서 결과까지 단 몇 초예요.

1) 휠 선택 또는 생성

프리셋을 고르거나 이모지와 색상으로 직접 조각을 만들어보세요.

2) 가중치와 옵션 설정

확률, 스핀 속도, 햅틱, 중첩 링크를 세밀하게 조정하세요.

3) 스핀 탭하기

휠이 실감 나게 감속하며 돌아가는 모습을 지켜보세요.

4) 결과 확인

컨페티와 함께 당첨자를 확인하세요 — 다시 돌리거나 하위 휠을 열어보세요.
