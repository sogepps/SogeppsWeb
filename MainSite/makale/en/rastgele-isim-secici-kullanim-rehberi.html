Random Name Picker: Usage Guide for Classroom, Office, and Home

Quick Raffle 27 August 2026·2 min read

A random name picker looks like a simple tool, but its real job isn't to pick — it's to end the argument. If the answer to "Why me always?" is an app, no one gets hurt.

In class: speaking order and group formation

  • Speaking rights: In classes where only the same students raise their hands, random selection balances participation.
  • Presentation order: When you draw with elimination mode, each student comes out once and the order builds itself.
  • Group work: Team selector prevents friend groups from always staying together.
  • Turns and duties: Weekly drawing for tasks like erasing the board, tidying up.

In the office: fair distribution

There are tasks no one volunteers for: taking meeting notes, opening the presentation, weekend duty. Distributing these randomly is both fast and not taken personally.

  • Determining who takes notes in the meeting.
  • Drawing presentation order.
  • Setting up year-end gift exchange (Secret Santa) pairings.
  • Building pair work groups within the team.

At home: chore sharing and decisions

  • Drawing weekly for dishes, trash, grocery shopping.
  • Determining order for movie or series selection.
  • Fairly distributing game order among children.
  • Deciding who orders what.

The difference between elimination mode and regular picking

In regular mode, all names are in the pool each draw; the same person can come up multiple times in a row. In elimination mode, the drawn name is removed from the pool, so no one comes out again until everyone has been selected once.

If you're looking for a single winner, regular mode is the right tool; if you're building an order, elimination mode is.

When is team selector better?

Using team selector instead of drawing names one by one and manually writing teams both saves time and divides teams evenly. When you set the team count, the app distributes names equally; if there are extra players, it spreads the overflow between teams.

More than 15 tools in one app

Quick Raffle combines name picker, number draw, spinner, bag, team selector, dice, coin flip, card draw, list shuffle, bingo, yes/no, Secret Santa, tournament bracket, and password generator in one app. All work offline and results are generated fairly.

Frequently Asked Questions

Can the same name come out twice?

In regular mode yes, because all names are in the pool each draw. If you don't want repeats, use elimination mode; the drawn name is removed from the pool.

How do I divide teams equally?

Just enter names in team selector and specify the team count. If the player count doesn't divide evenly, extra people are distributed evenly to teams.

Does it work without internet?

Yes. Raffle and selection happen on your device, so no internet connection is needed.
