Online Drawing: How to Draw Lots for Class, Workplace, and Tournament?

Quick Raffle 3 September 2026·2 min read

Drawing seems simple, but drawing it so no one disputes the result is another matter. Folding slips of paper and tossing them in a hat still works; the problem is who holds that hat.

Types of raffles and when to use each

  • Name draw: If one person is being selected. Turns, presentation order, winner.
  • Number draw: Selection from numbered participants. Order number, ticket number.
  • Team draw: Dividing a crowd into balanced groups. Class project, futsal teams.
  • Order draw: When everyone needs to come out once. Use elimination mode; the drawn name is removed from the pool.
  • Pairing draw: To create pairs. Secret Santa, pair work.

Four conditions for a fair raffle

  • List must be finalized beforehand. If someone says "I was supposed to be included" after the draw, the raffle has to be redone.
  • Everyone should have equal rights. Don't use weight in the raffle; weight is for games, not raffles.
  • Process must be visible. Screen share or screen recording is the most effective objection preventer.
  • Result must be recorded. A screenshot of the draw moment prevents any argument that comes up later.

Raffle in the classroom

Three scenarios teachers use most: speaking rights, presentation order, and group formation.

  • For speaking rights use a regular name picker — the full list stays in the pool each time.
  • For presentation order use elimination mode — everyone comes out once, order builds itself.
  • For group formation use team selector — prevents friend groups from staying together.

Raffle in the workplace

  • Shift and duty allocation — no one can say "it always falls on me."
  • Who takes notes in the meeting — quickest solution for work no one volunteers for.
  • Year-end Secret Santa pairing — with pairing raffle.
  • Pair work groups — with team selector.

Tournament raffle

In tournaments, the raffle ensures the bracket is set up fairly. Pay attention to two things: seeds should not be randomly distributed (strong teams shouldn't meet in the first round) and byes should go to top seeds.

If participant count is not a power of two (not 8, 16, or 32), some skip the first round without playing; this distribution is determined by ranking, not raffle, or the format becomes unfair internally.

The difference between using paper and using an app

  • List stays recorded, doesn't have to be rewritten each time.
  • Result comes out instantly, no time for folding and shuffling.
  • Thanks to elimination mode, the same name doesn't come up twice.
  • With screen share, the process is visible to everyone at the same time.
  • No internet needed; works offline in class or on the field.

Frequently Asked Questions

Is an online raffle reliable?

As long as the list is entered correctly and weight isn't used, each participant has equal probability. Showing the process with screen share is the most practical way to build trust.

How do I prevent the same person from being drawn twice?

Use elimination mode. The drawn name is removed from the pool, so no one comes out twice until everyone has been selected once.

How do I divide teams fairly?

Enter names in the team selector and specify the team count. If the number doesn't divide evenly, extra people are distributed evenly to teams.
