Cara Bermain Okey 101? Perbedaan dari Okey Klasik

Metin2 Okey 3 September 2026·3 menit baca

Okey 101 adalah sepupu Okey klasik yang lebih panjang dan lebih strategis. Dimainkan dengan 106 ubin yang sama tetapi ada ambang untuk pertama kalinya keluar: kamu tidak bisa membuka sampai total nilai set di tanganmu setidaknya 101 poin. Aturan tunggal inilah yang membuat permainan benar-benar berbeda.

Penyiapan dasar

  • Pemain: 4 orang.
  • Ubin: Sama seperti okey klasik — dua set masing-masing angka 1-13 dalam empat warna, ditambah dua ubin dummy; total 106.
  • Pembagian: Setiap pemain mendapat 21 ubin, pemain awal mendapat 22 ubin.
  • Indikator dan okey: Ditentukan seperti di klasik — ubin okey adalah satu tingkat di atas indikator warna yang sama.

Aturan 101: ambang pembukaan tangan

Nama permainan berasal dari sini. Untuk membuka set di meja, total nilai set yang kamu buka minimal harus 101 poin Jika kamu tidak mencapai ambang ini, kamu terus memegang.

Dalam penghitungan poin, ubin dihitung berdasarkan nilai numerik mereka. Detail (berapa nilai ubin 1, nilai okey, status set ganda) adalah aturan rumah yang dapat berbeda dari meja ke meja; mengklarifikasi ini sebelum memulai permainan mencegah perdebatan paling umum.

Set yang valid

  • Urutan: Minimal tiga ubin berurutan dari warna yang sama — kuning 5, kuning 6, kuning 7.
  • Kelompok: Minimal tiga ubin dari angka yang sama dalam warna berbeda — biru 9, hitam 9, merah 9.
  • Kelompok tidak dapat memiliki dua warna yang sama.
  • Ubin okey menggantikan ubin apa pun yang kamu inginkan; ubin dummy juga menggantikan okey.

Pemrosesan: setelah membuka

Setelah membuka tangan, permainan berubah. Sekarang kamu bisa menambahkan ubin baik ke set milikmu sendiri maupun ke set pemain lain di meja. Ini disebut pemrosesan dan merupakan cara utama untuk dengan cepat menyingkirkan tangan kamu.

Tidak ada fase seperti ini di okey klasik; permainan didasarkan pada menyelesaikan dengan satu gerakan. Dalam 101, ada permainan terpisah antara pembukaan dan penyelesaian — dan sebagian besar pertandingan dimenangkan dan kalah di sini.

Penyelesaian dan penilaian

  • Pemain yang mengubah semua ubin di tangannya menjadi set dan membuang ubin terakhir menyelesaikan tangan.
  • Pemain yang tidak menyelesaikan menerima poin penalti sebesar nilai ubin yang tersisa di tangan mereka.
  • Poin bekerja menurun: pemain mulai dari skor awal dan yang mencapai nol terlebih dahulu menang — atau menurut preferensi meja, yang mengumpulkan poin penalti paling sedikit.
  • Perhitungan poin penalti dan skor awal juga dapat berbeda menurut aturan rumah; bicarakan dari awal.

Perbedaan antara Okey Klasik dan 101

  • Jumlah ubin: Klasik 14, 101 memiliki 21 ubin.
  • Pembukaan: Tidak ada pembukaan di klasik; ada ambang 101 poin di 101.
  • Pemrosesan: Tidak ada di klasik, ada di 101.
  • Durasi: Tangan klasik beberapa menit, tangan 101 secara signifikan lebih lama.
  • Strategi: Kecepatan di klasik, perencanaan menentukan di 101.

Tiga tips untuk pemula

  • Targetkan ambang pembukaan lebih awal; pemain yang membuka terlambat tidak bisa menggunakan fase pemrosesan.
  • Jangan kumpulkan ubin angka tinggi (10-11-12-13) di tanganmu — jika tidak menyelesaikan, poin penalti kamu akan membengkak.
  • Menyimpan okey untuk penyelesaian daripada menggunakannya di pembukaan biasanya lebih menguntungkan di sebagian besar tangan.

Pertanyaan yang Sering Diajukan

Berapa banyak ubin dibagikan di Okey 101?

Setiap pemain mendapat 21 ubin, pemain awal mendapat 22 ubin. Ini jauh lebih banyak dari 14 ubin di okey klasik.

Apa maksud 101 poin?

Untuk membuka set di meja, total nilai set yang kamu buka harus minimal 101. Kamu tidak bisa membuka sampai mencapai ambang ini.

Apa perbedaan dasar antara Okey 101 dan okey klasik?

Ada dua perbedaan besar: di 101 21 ubin dibagikan dan ada ambang 101 poin untuk pembukaan; juga ada fase "pemrosesan" di mana kamu bisa menambahkan ubin ke set di meja setelah membuka.
