Comment Jouer à Sessiz Kelime ? Règles et Notation

Sessiz Kelime 27 août 2026·2 min de lecture

Sessiz Kelime est un jeu d'équipe qui se situe à l'intersection du cinéma muet et du tabou : un mot apparaît à l'écran, la personne qui explique ne peut pas parler, les coéquipiers essaient de deviner. Les règles sont courtes, maintenir le rythme rapide dépend entièrement des paramètres.

Configuration : deux équipes, un téléphone

Les joueurs sont divisés en deux équipes. Le téléphone est tenu par la personne qui explique ; l'écran ne le voit que lui. Quand le minuteur démarre, le mot apparaît et l'explication commence.

  • Gardez les équipes à nombre égal ; s'il y a une personne supplémentaire, elle change d'équipe à chaque tour.
  • L'explicateur change à chaque tour ; la même personne ne doit pas expliquer d'affilée.
  • Choisissez la catégorie en fonction du groupe : une catégorie mixte est le meilleur départ équilibré.

Règles d'explication

  • Pas de parole — aucun son, aucun mot de la parole ne peut être prononcé.
  • Pas de lettres ou de syllabes.
  • Montrer un objet est autorisé, mais écrire le mot est interdit.
  • Les coéquipiers peuvent deviner autant de fois qu'ils le souhaitent.

Notation : correct, incorrect, passe

Le système de notation se compose de trois résultats et l'explicateur les marque avec un geste de balayage.

  • Correct (+1) — L'équipe a trouvé le mot.
  • Incorrect (−1) — Il y a eu violation de règle ou l'explicateur a abandonné.
  • Passe (0) — Le mot est passé ; le droit de passe est limité.

Que changent les réglages de durée et de passe ?

Quand la durée du tour descend en dessous de 60 secondes, le jeu s'accélère mais le nombre de devinettes par mot diminue. Au-dessus de 90 secondes, les équipes se détendent et le rythme baisse. Pour la plupart des groupes, 60–75 secondes est le meilleur équilibre.

Le droit de passe est une courbe de difficulté : les passes illimitées rendent le jeu facile, deux passes forcent l'explicateur à affronter des mots difficiles.

Conseils pour les grands groupes

  • Pour les groupes de plus de 8 personnes, créez trois équipes ; le temps d'attente diminue.
  • Limitez le nombre de catégories ; un bassin trop large rend l'explication difficile.
  • Déterminez le nombre de tours à l'avance, ne prolongez pas le jeu avec "un tour de plus".

Questions Fréquemment Posées

Avec combien de personnes Sessiz Kelime se joue-t-il ?

Un minimum de 4 personnes est requis (deux équipes, deux joueurs chacun). La plage la plus agréable est 3–5 joueurs par équipe.

Est-il autorisé de faire du bruit en expliquant ?

Non. Selon les règles classiques, l'explicateur n'émet aucun son. Si votre groupe le souhaite, vous pouvez aussi jouer avec une variante assouplie : "le son est libre, le mot est interdit".

Combien de passes devrait-il y avoir ?

2 passes par tour est équilibré pour la plupart des groupes. Les passes illimitées rendent le jeu facile, zéro passe peut bloquer les tours sur des mots difficiles.
