Comment jouer à HomeParty

Un déroulement simple, de la configuration aux scores finaux.

1) Ajoutez les joueurs

Définissez le nombre de joueurs selon le mode de jeu choisi.

2) Choisissez un jeu

Choisissez le mode qui correspond le mieux à l'ambiance du moment.

3) Faites circuler le téléphone

La plupart des modes sont conçus pour passer facilement de main en main.

4) Terminez et comptez les points

Consultez automatiquement les résultats, votes, points et gagnants.
